# Игра «Крестики-нолики»

Консольная игра «Крестики-нолики» на Java. В проекте используются несколько
шаблонов проектирования для разделения ответственности и упрощения расширения
игры.

## Требования

- JDK 8 или новее

## Компиляция и запуск

Перейдите в каталог `java_3` и выполните:

```bash
mkdir -p out
javac -d out src/*.java
java -cp out Main
```

Во время игры вводите номер строки и столбца через пробел, например:

```text
2 3
```

## Шаблоны проектирования

### Singleton — `Game`

Класс `Game` предоставляет единственный экземпляр игры через метод
`Game.getInstance(...)`. Конструктор закрыт, поэтому создать второй экземпляр
игры напрямую нельзя.

### Factory — `PlayerFactory`

`PlayerFactory` создаёт нужный тип игрока по строковому параметру:

```java
Player human = PlayerFactory.createPlayer("human", "Игрок", Mark.X);
Player computer = PlayerFactory.createPlayer("ai", "Компьютер", Mark.O);
```

Поддерживаются типы `human` и `ai`. Добавление новых типов игроков не требует
изменений в коде, который запускает игру.

### Builder — `Board.Builder`

`Board.Builder` позволяет гибко создавать игровое поле и задавать его размер:

```java
Board board = Board.builder()
        .size(5)
        .build();
```

Размер поля по умолчанию — 3×3.

### Dependency Injection

Зависимости `Board`, `Player` и `Scanner` передаются в `Game` извне через
параметры `Game.getInstance(...)`. Благодаря этому `Game` не создаёт свои
зависимости самостоятельно, а классы можно заменять и тестировать отдельно.
